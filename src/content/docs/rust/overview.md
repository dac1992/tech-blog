Rust 是一门系统级编程语言，由 Mozilla 于 2010 年发布，1.0 版本于 2015 年稳定。Rust 在保持高性能的同时，通过所有权系统在编译期消除内存安全问题，连续多年蝉联 Stack Overflow "最受喜爱语言"榜首。

## 核心特性

- **零成本抽象** — 高层抽象不带来运行时开销
- **所有权系统** — 编译期保证内存安全，无需垃圾回收
- **无数据竞争** — 类型系统在编译期消除数据竞争
- **模式匹配** — 强大的枚举与模式匹配
- **零开销 FFI** — 无缝调用 C 语言函数

## 版本发布

Rust 每 6 周发布一个稳定版，每年发布一个 Edition（语义层级的大版本）：

| Edition | 年份 | 重点 |
|---------|------|------|
| 2015 | 2015 | 初始稳定版 |
| 2018 | 2018 | 模块系统改进、异步 await |
| 2021 | 2021 | 闭包捕获优化、新的 prelude |
| 2024 | 2024 | 生命周期捕获规则改进、`gen` 语法 |

## 应用领域

- **系统编程** — 操作系统内核、驱动程序
- **WebAssembly** — 高性能前端模块
- **嵌入式** —物联网设备固件
- **CLI 工具** — 高性能命令行工具（ripgrep、fd、bat）
- **网络服务** — 高并发后端服务
