Java 是一门面向对象的编程语言，由 Sun Microsystems（现属 Oracle）于 1995 年发布。凭借"一次编写，到处运行"的理念，Java 已成为全球最受欢迎的编程语言之一，广泛应用于企业级开发、移动应用、大数据处理和云原生领域。

## 核心特性

- **平台无关性** — 编译为字节码，由 JVM 解释执行，跨平台运行
- **面向对象** — 封装、继承、多态三大核心特性
- **自动内存管理** — 内置垃圾回收器，无需手动管理内存
- **强类型与安全性** — 编译期和运行期严格类型检查
- **多线程支持** — 语言层面内置并发编程工具

## 版本演进

| 版本 | 发布年份 | 里程碑特性 |
|------|---------|-----------|
| Java 8 | 2014 | Lambda 表达式、Stream API、Optional |
| Java 11 | 2018 | HTTP Client、var 局部变量推断、首个 LTS |
| Java 17 | 2021 | 密封类、模式匹配（Preview） |
| Java 21 | 2023 | 虚拟线程、模式匹配（Finalized）、记录模式 |

:::tip[LTS 推荐]
当前推荐的长期支持版本为 **Java 21**，包含虚拟线程等重大特性。
:::

## 应用领域

- **企业级后端** — 银行、电商、物流等核心业务系统首选
- **Android 开发** — 原生 Android 应用开发语言
- **大数据** — Hadoop、Spark、Flink、Kafka 均基于 JVM
- **云原生** — GraalVM 原生镜像让启动时间降至毫秒级

## 学习路线

1. 掌握基础语法与面向对象思想
2. 熟悉常用框架（Spring Boot、MyBatis）
3. 深入并发编程与 JVM 调优
4. 了解云原生与微服务架构
