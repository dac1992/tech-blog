Java 是一门面向对象、平台无关的编程语言，由 Sun Microsystems 于 1995 年发布。凭借"一次编写，到处运行"的理念，Java 已成为全球最受欢迎的编程语言之一，广泛应用于企业级开发、移动应用、大数据处理和云原生领域。

## 为什么选择 Java？

- **成熟的生态系统**：数十年的积累造就了庞大的类库、框架和工具链
- **企业级标准**：Spring 生态是后端开发的事实标准
- **高性能 JVM**：JIT 编译、GC 优化让 Java 性能持续进化
- **云原生就绪**：GraalVM 原生镜像让 Java 启动速度进入毫秒级
- **就业市场广阔**：金融、电商、互联网大厂的核心技术栈

## 核心特性

| 特性 | 说明 |
|------|------|
| 平台无关性 | 字节码 + JVM 实现跨平台运行 |
| 自动内存管理 | GC 自动回收，降低内存泄漏风险 |
| 强类型系统 | 编译期和运行期双重类型检查 |
| 多线程内置 | 语言层面支持并发编程 |
| 丰富的标准库 | JDK 提供网络、IO、集合、并发等全套工具 |

## 版本演进

| 版本 | 年份 | 关键特性 |
|------|------|---------|
| Java 8 | 2014 | Lambda、Stream API、Optional |
| Java 11 | 2018 | var 关键字、HTTP Client、首个 LTS |
| Java 17 | 2021 | 密封类、模式匹配（Preview） |
| Java 21 | 2023 | 虚拟线程、记录模式、模式匹配（Final） |
