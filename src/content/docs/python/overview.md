Python 由 Guido van Rossum 于 1991 年发布，以"优雅、简洁、可读"为设计哲学，已成为全球最流行的编程语言之一。Python 在数据科学、AI/ML、Web 开发、自动化等领域占据主导地位。

## 核心特性

- **简洁易读** — 语法接近自然语言，开发效率极高
- **动态类型** — 灵活的类型系统，减少样板代码
- **丰富生态** — PyPI 拥有 50 万+ 第三方包
- **多范式** — 面向对象、函数式、过程式均可
- **胶水语言** — 轻松集成 C/C++ 库

## 版本演进

| 版本 | 年份 | 重点 |

| 3.6 | 2016 | f-string、类型标注增强 |
| 3.8 | 2019 | 海象运算符 `:=`、位置参数 |
| 3.10 | 2021 | 模式匹配 match/case |
| 3.11 | 2022 | 速度提升 10-60%、异常组 |
| 3.12 | 2023 | 更好的 f-string、类型参数语法 |
| 3.13 | 2024 | 实验性 GIL-free、JIT 编译器 |

:::tip[版本选择]
推荐使用 **Python 3.12+**，性能优异且生态兼容性好。
:::
