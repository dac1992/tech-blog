Python 是一门由 Guido van Rossum 于 1991 年创建的高级编程语言。以简洁优雅的语法和强大的生态著称，Python 是数据科学、人工智能、Web 开发和自动化脚本的首选语言。

## 为什么选择 Python？

- **语法简洁**：接近自然语言，代码可读性极强
- **生态庞大**：PyPI 拥有超过 50 万个第三方包
- **AI/ML 首选**：TensorFlow、PyTorch、Scikit-learn 等主流框架
- **全栈能力**：Web、数据分析、自动化、桌面应用无所不能
- **跨平台**：Windows、macOS、Linux 完美支持
- **活跃社区**：丰富的文档、教程和开源项目

## 核心特性

| 特性 | 说明 |
|------|------|
| 动态类型 | 无需声明变量类型，开发效率高 |
| 解释执行 | 无需编译，即写即运行 |
| 面向对象 | 一切皆对象，支持类与继承 |
| 函数式支持 | Lambda、map/filter/reduce、生成器 |
| 丰富的标准库 | os、sys、json、re、datetime 等内置 |

## 典型应用领域

- **数据科学与分析**：Pandas、NumPy、Matplotlib、Jupyter
- **人工智能/机器学习**：TensorFlow、PyTorch、Transformers
- **Web 开发**：Django、Flask、FastAPI
- **自动化与脚本**：Selenium、Requests、BeautifulSoup
- **DevOps**：Ansible、Fabric、SaltStack
